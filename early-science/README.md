# ePIC SIDIS studies

This repository contains studies of Semi-Inclusive Deep Inelastic Scattering (SIDIS) processes for the ePIC collaboration, focusing on the early science condition.

The directory 'Pseudodata_26.04.1_10x250' contains all the produced tables for the impact studies.
  - Normal_sys: Use the systematics defined by the ATHENA proposal (arXiv:2210.09048).
  - Enhanced_sys: Here the 'point-to-point systematic is doubled.

Inside there is the data for $K^{+},K^{-},\pi^{+},\pi{-}$ for all the 4 configuration of $Q^{2}$:
  - $1 < Q^{2} < 10 \ GeV^{2} \ \rightarrow \ 5M$ event generated. 
  - $10 < Q^{2} < 100 \ GeV^{2} \ \rightarrow \ 5M$ event generated.
  - $100 < Q^{2} < 1000 \ GeV^{2} \ \rightarrow \ 5M$ event generated.
  - $1000 < Q^{2} < 10000 \ GeV^{2} \ \rightarrow \ 0.5M$ event generated.

The statistic for the cross-section is projected to $2.5 fb^{-1}$.
